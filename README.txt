Health Buddy 🩺 - Python Mini Project for BCA Semester 2
-------------------------------------------------------

📌 Project Overview:
This is a simple console-based health assistant built using Python. It allows users to:
- Input basic health data (name, age, weight, height, glucose level)
- Calculate and categorize BMI
- Predict diabetes risk based on glucose level and BMI
- Save records in a CSV file
- View saved records anytime

🎯 Features:
- BMI calculation and classification
- Diabetes risk assessment (Low, Moderate, High)
- CSV record storage using pandas
- Safe error-handling (no crashes even if file doesn't exist)
- Clean, user-friendly CLI interface

📁 Files Included:
- health_buddy.py       → Main Python script
- records.csv           → Auto-created file storing records (optional, created on first entry)
- README.txt            → This file with project description

🔧 Requirements:
Make sure the following Python modules are installed:
- pandas

Install using:
    pip install pandas

▶️ How to Run:
Open terminal or IDLE, navigate to the folder, and run:

    python health_buddy.py
